# The Little Kitchen

Live website: https://abhishekgb1.github.io/Interactive-Recipe-Card-with-Animations/

A warm, responsive recipe collection with six recipes, food photography, ingredient checklists, guided cooking steps and a countdown timer.

## Features
- Desktop recipe tabs and a mobile recipe selector.
- Ingredient checklists and keyboard-accessible collapsible sections.
- Cooking timer, step highlighting, reset and completion controls.
- Print recipe button and print layout.
- Reduced-motion support and local image fallback.

## Development
No dependencies or build step. Serve this folder with any static HTTP server. Files: index.html (structure), styles.css (design), app.js (recipes and interactions), assets/ (photography and fallback artwork).

The original HTML filename forwards to the homepage. The original reference screenshots are preserved. Photography is illustrative; avocado and potato photos show ingredients.

## Hosting
GitHub Pages publishes main / (root) automatically. Keep the account, repository and Pages enabled to retain this URL. There is no scheduled expiry; perpetual hosting cannot be guaranteed.
