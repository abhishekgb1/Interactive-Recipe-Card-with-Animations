# Recipe Kitchen

Live website: https://abhishekgb1.github.io/Interactive-Recipe-Card-with-Animations/

Six recipes with ingredient checklists, keyboard-accessible collapsible sections, a cooking countdown, step highlighting, reset and completion controls. Supports mobile screens, printing and reduced motion.

## Hosting
GitHub Pages publishes main / (root) automatically. Keep the account, repository and Pages enabled to retain this URL. There is no scheduled expiry, but perpetual hosting cannot be guaranteed.

## Development
No dependencies or build step. Serve this folder with a static HTTP server and open index.html. Recipe data and application code are in index.html. The original HTML filename forwards to the homepage. Screenshots are preserved.

Recipe header graphics use placeholders from placehold.co. Fonts load from Google Fonts. The core recipe content and interactions work without those external assets.
